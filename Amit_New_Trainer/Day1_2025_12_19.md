Variables
---------
A variable is a container for storing data. Common data types:

- Integer: 10, 20
- Float: 44.5, 55.6
- String: "Rishi", "India is my country"
- Character: 'a', 'b' (Python does not have a separate char type — these are strings of length 1)
- Boolean: True, False

Defining a variable

variablename = value

Examples

```py
a = 10        # integer
b = "Rishi"  # string
c = 'a'       # string of length 1
```

Naming conventions

1. Prefer lowercase names (snake_case) for variables.
2. Keep names short and meaningful (e.g. city = "Delhi").
3. Do not use spaces or special characters: city name = "Lucknow"  <- invalid.
4. Use underscores if needed: city_name = "Delhi".
5. CamelCase is typically reserved for class names: CityName = "Hyderabad".

Comments
--------
Comments are used to explain code and are ignored by Python.

**Single-line comments** use `#`:

```python
# This is a comment
x = 10  # Set x to 10
```

**Multi-line comments** use triple quotes:

```python
'''
This is a multi-line comment.
It can span multiple lines.
Used for docstrings too.
'''

"""
Alternatively, use double quotes.
"""
```

Input and Output
----------------

### print() - Display output

The `print()` function displays text or values to the console:

```python
print("Hello, World!")  # Hello, World!
print(10)               # 10
print("Age:", 25)      # Age: 25
```

### input() - Get user input

The `input()` function reads input from the user as a string:

```python
name = input("Enter your name: ")
print("Hello, " + name)

age = int(input("Enter your age: "))  # Convert to integer
print("You are", age, "years old")
```

**Note:** `input()` always returns a string, so use `int()`, `float()`, etc. to convert if needed.

String Data Type
-----------------

### Creating Strings

```python
s1 = "Hello World"  # Double quotes
s2 = 'Python'       # Single quotes
s3 = """Multi
line
string"""  # Triple quotes for multi-line
```

### String Length

```python
text = "Python"
print(len(text))  # 6
```

### String Indexing

```python
text = "Python"
print(text[0])   # P (first character)
print(text[-1])  # n (last character)
print(text[1:4]) # yth (characters from index 1 to 3)
```

### String Concatenation

```python
first = "John"
last = "Doe"
full_name = first + " " + last
print(full_name)  # John Doe

# Using f-strings (Python 3.6+)
print(f"Hello, {first} {last}!")  # Hello, John Doe!
```

### String Methods

```python
text = "Hello World"
print(text.lower())      # hello world
print(text.upper())      # HELLO WORLD
print(text.replace("World", "Python"))  # Hello Python
print(text.split())      # ['Hello', 'World']
```

Escape Sequences
-----------------

Escape sequences are special character combinations:

| Sequence | Meaning |
|---|---|
| `\n` | New line |
| `\t` | Tab |
| `\\` | Backslash |
| `\'` | Single quote |
| `\"` | Double quote |
| `\r` | Carriage return |

### Examples

```python
print("Line 1\nLine 2")    # Output on two lines
print("Name\tAge")         # Name    Age (with tab space)
print("Path: C:\\Users\\Name")  # Path: C:\Users\Name
print("He said, \"Hello!\"")      # He said, "Hello!"
```

Type Conversion (Type Casting)
-------------------------------

Convert values from one type to another:

```python
# String to Integer
x = int("10")
print(x + 5)  # 15

# Integer to String
y = str(20)
print(y + " apples")  # 20 apples

# String/Integer to Float
z = float("3.14")
print(z)  # 3.14

# Integer to Boolean
print(bool(1))   # True
print(bool(0))   # False
```

Operators
---------
Operators perform operations on values. Common operator types:

### 1. Arithmetic Operators

```python
a = 10
b = 3

print(a + b)   # 13 (Addition)
print(a - b)   # 7 (Subtraction)
print(a * b)   # 30 (Multiplication)
print(a / b)   # 3.333... (Division)
print(a % b)   # 1 (Modulus - remainder)
print(a ** b)  # 1000 (Exponentiation)
print(a // b)  # 3 (Floor Division)
```

### 2. Comparison Operators

```python
x = 5
y = 10

print(x == y)  # False (Equal to)
print(x != y)  # True (Not equal to)
print(x < y)   # True (Less than)
print(x > y)   # False (Greater than)
print(x <= y)  # True (Less than or equal)
print(x >= y)  # False (Greater than or equal)
```

### 3. Logical Operators

```python
a = True
b = False

print(a and b)  # False (Both must be True)
print(a or b)   # True (At least one must be True)
print(not a)    # False (Inverts the value)
```

### 4. Assignment Operator

```python
x = 10        # Simple assignment
x += 5        # x = x + 5 (15)
x -= 3        # x = x - 3 (12)
x *= 2        # x = x * 2 (24)
x /= 4        # x = x / 4 (6.0)
```

**Note:** Python does not support `++` or `--` increment/decrement operators.
