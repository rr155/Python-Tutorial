# Python - Lists

## Create List

```python
x = [10,20,30]
print(x[2])  # 30
```

## Slicing List - Cut (x:y)

```python
x = [10,20,30]
print(x[1:3])  # [20, 30]
```

## Modify List

```python
x = [10,20,30]
x[1] = 25
print(x)  # [10, 25, 30]
```

## List Methods

### append() - Insert a new value at the end

```python
x = [10,25,30]
x.append(35)
print(x)  # [10, 25, 30, 35]
```

### insert() - Insert a value at specific position

```python
y = [15,25,35]
y.insert(1,17)
print(y)  # [15, 17, 25, 35]
```

### pop() - Deletes the last value from list

```python
y = [15,17,25,35]
y.pop()
print(y)  # [15, 17, 25]
```

### remove() - Delete the specific value from list

```python
y = [15,17,25]
y.remove(17)
print(y)  # [15, 25]
```

### del - Remove value at specific position

```python
y = [15,25]
del y[0]
print(y)  # [25]
```

### clear() - Delete all values from list

```python
x = [10,25,30]
x.clear()
print(x)  # []
```

### sort() - Sort values in ascending order

```python
z = [5,2,9,1]
z.sort()
print(z)  # [1, 2, 5, 9]
```

## Looping Through Lists

### Method 1: Direct iteration

```python
fruits = ["Apple","Banana","Mango"]

for k in fruits:
    print(k)
```

### Method 2: Using range() and len()

```python
fruits = ["Apple","Banana","Mango"]

for i in range(len(fruits)):
    print(fruits[i])
```

## Nested Lists

```python
students = [
    [10,20],
    [75,85]
]
print(students[0][1])  # 20
```

## Remove Duplicate Values with set()

```python
numbers = [1,2,2,3,4,4,5]
unique = list(set(numbers))
print(unique)  # [1, 2, 3, 4, 5]
```

## Search in List with in()

```python
x = [1,2,3,4]

if 2 in x:
    print("Found")
else:
    print("Not Found")
```

## Convert String to List

```python
text = "Python"
z = list(text)
print(z)  # ['P', 'y', 't', 'h', 'o', 'n']
```

## Split String to List

```python
s = "I love India"
z1 = s.split()
print(z1)  # ['I', 'love', 'India']
```

## String to List (Single Element)

```python
name = "John"
k = [name]
print(k)  # ["John"]
```

# Tuples

## Introduction

- Collection of data
- Immutable - Cannot be modified
- Enclosed in ()
- Read-only list

## Key Features

- Immutable (cannot be changed)
- Allow duplicate values
- Faster than lists
- Use parentheses ()

## Create and Display Tuple

```python
x = (10,20,30,40,50,60)
for k in x:
    print(k)
```

## Slicing Tuple

```python
x = (10,20,30,40,50,60)
print(x[1:4])  # (20, 30, 40)
```

## Concatenation of Tuples

```python
x = (10,20,30,40,50,60)
y = (75,80,-40)
z = x + y
print(z)  # (10, 20, 30, 40, 50, 60, 75, 80, -40)
```

## Delete Tuple

```python
x = (10,20,30)
del x
# print(x)  # This will raise an error
```

## sum() - Sum of all values

```python
newt = (10,20,30)
print(sum(newt))  # 60
```

## reversed() - Reverse tuple values

```python
newt = (10,20,30)
t = tuple(reversed(newt))
print(t)  # (30, 20, 10)
```

## sorted() - Sort in ascending order

```python
g = (5,2,9,1)
sort_t = sorted(g)
print(sort_t)  # [1, 2, 5, 9]
print(type(sort_t))  # <class 'list'>
```

## Convert to tuple after sorting

```python
g = (5,2,9,1)
sort_t = sorted(g)
newk = tuple(sort_t)
print(newk)  # (1, 2, 5, 9)
```

## Sorted in descending order

```python
g = (5,2,9,1)
sorted_list = sorted(g, reverse=True)
print(tuple(sorted_list))  # (9, 5, 2, 1)
```

## Convert List to Tuple and Vice Versa

```python
g = (10,20,30)
k = list(g)
print(k)  # [10, 20, 30]
```

### Convert empty list to empty tuple

```python
lst = []
t = tuple(lst)
print(t)  # ()
```

### Convert nested list to tuple

```python
lst = [[1,2],[3,4]]
t = tuple(lst)
print(type(t[0]))  # <class 'list'>
```
