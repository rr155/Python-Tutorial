## Understanding range() Function

The `range()` function generates a sequence of numbers. It takes up to 3 parameters:
- `range(stop)` - Numbers from 0 to stop-1
- `range(start, stop)` - Numbers from start to stop-1
- `range(start, stop, step)` - Numbers from start to stop-1 with given step

### Examples

```python
# From 0 to 4
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4

# From 2 to 7
for i in range(2, 8):
    print(i)  # 2, 3, 4, 5, 6, 7

# From 0 to 10 with step of 2
for i in range(0, 11, 2):
    print(i)  # 0, 2, 4, 6, 8, 10

# Reverse order (step -1)
for i in range(5, 0, -1):
    print(i)  # 5, 4, 3, 2, 1
```

## Nested Loops

A loop inside another loop. Useful for patterns and matrices:

```python
# Print a multiplication table
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} x {j} = {i*j}")
    print()  # Blank line

# Output:
# 1 x 1 = 1
# 1 x 2 = 2
# 1 x 3 = 3
#
# 2 x 1 = 2
# 2 x 2 = 4
# 2 x 3 = 6
# ... and so on
```

### Nested Loop Example - Print patterns

```python
# Triangle pattern
for i in range(1, 5):
    for j in range(i):
        print("*", end=" ")
    print()

# Output:
# *
# * *
# * * *
# * * * *
```

## for-else Statement

Python allows an `else` block after a `for` loop. The `else` block executes if the loop completes normally (without `break`):

```python
# Example 1: Loop completes normally
for i in range(3):
    print(i)
else:
    print("Loop completed!")

# Output:
# 0
# 1
# 2
# Loop completed!

# Example 2: Loop breaks early
for i in range(5):
    if i == 3:
        break
    print(i)
else:
    print("Loop completed!")  # This won't print

# Output:
# 0
# 1
# 2
```

## while-else Statement

Similar to `for-else`, the `else` block executes after a `while` loop if it completes normally:

```python
# Example: while-else
i = 0
while i < 3:
    print(i)
    i += 1
else:
    print("While loop finished!")

# Output:
# 0
# 1
# 2
# While loop finished!

# Example: while-else with break
i = 0
while i < 5:
    if i == 2:
        print("Breaking out!")
        break
    print(i)
    i += 1
else:
    print("Loop finished!")  # Won't execute

# Output:
# 0
# 1
# Breaking out!
```

# Jump Statements

## Introduction
- Used to control the loop execution

## Types

### 1. break

Stops/terminates the loop at a specific condition.

```python
for i in range(1, 21):
    if i == 12:
        break
    print(i)
```

### 2. continue

Skips a specific condition and continues executing the loop.

```python
for i in range(1, 21):
    if i == 5:
        continue
    print(i)
```

### 3. pass

Does nothing. Used when a statement is required syntactically but you don't want to execute any code.

```python
for i in range(1, 21):
    pass

print('Hello World')
```
