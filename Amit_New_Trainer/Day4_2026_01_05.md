# Sets

**Characteristics:**
- Contains unique values
- Mutable (can be modified)
- Syntax: `{ }`

## Set Methods

### `intersection()` - Return Common Elements

Returns elements that are present in both sets.

```python
a = {1, 2, 3}
b = {2, 3, 4}
c = a.intersection(b)
print(c)  # {2, 3}
```

### `union()` - Combine Sets

Combines two sets into a single set.

```python
a = {10, 20}
b = {30, 40}
c = a.union(b)
print(c)  # {10, 20, 30, 40}
```

### `clear()` - Remove All Elements

Removes all elements from a set.

```python
a = {1, 2, 3}
a.clear()
print(a)  # set()
```

### `copy()` - Copy a Set

Creates a copy of a set.

```python
b = {2, 3, 4}
z = b.copy()
print(z)  # {2, 3, 4}
```

### `max()` / `min()`

Returns the maximum and minimum values in a set.

```python
a = {10, 20, 30, 5}
print(max(a))  # 30
print(min(a))  # 5
```

### `difference()` - Find Differences

Returns elements in the first set that are not in the second set.

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
c = a.difference(b)
print(c)  # {1, 2}
```

### `add()` - Add Single Element

Adds a single element to the set.

```python
a = {1, 2, 3}
a.add(4)
print(a)  # {1, 2, 3, 4}
```

### `remove()` - Remove Specific Element

Removes a specified element from the set. Raises an error if the element doesn't exist.

```python
a = {1, 2, 3}
a.remove(2)
print(a)  # {1, 3}
```

### `discard()` - Remove Without Error

Removes a specified element if it exists. Does not raise an error if the element doesn't exist.

```python
a = {1, 2, 3}
a.discard(2)
print(a)  # {1, 3}
```

### `pop()` - Remove Random Element

Removes and returns an arbitrary element from the set.

```python
a = {1, 2, 3}
element = a.pop()
print(element)  # Random element
print(a)  # Remaining set
```

# Dictionary

**Characteristics:**
- Key-value pairs: `key:value`
- Mutable (can be modified)
- Syntax: `{key: value}`

## Dictionary Operations

### Accessing Values

```python
fees = {"anand": 5000, "ajay": 4000}
print(fees["anand"])  # 5000
```

### Adding Elements

```python
fees["sapna"] = 6000
print(fees["sapna"])  # 6000
print(fees)
```

### Deleting Elements

#### Using `del`
```python
del fees["ajay"]
print(fees)
```

#### Using `pop()`
Removes the element with the specified key.

```python
z = fees.copy()
z.pop("anand")
print(z)
```

#### Using `popitem()`
Removes the last inserted key-value pair.

```python
# Syntax: dict.popitem()
```

### Dictionary Methods

#### `clear()`
Removes all elements from the dictionary.

#### `copy()`
Creates a copy of the dictionary.

```python
z = fees.copy()
print(z)
```

#### `get()`
Returns the value of a specified key. Returns `None` if key doesn't exist (or a default value if specified).

```python
print(fees.get("sapna"))  # 6000
print(fees.get("unknown"))  # None
print(fees.get("unknown", "Not Found"))  # Not Found
```

#### `keys()`
Returns all keys in the dictionary.

```python
fees = {"anand": 5000, "ajay": 4000}
print(fees.keys())  # dict_keys(['anand', 'ajay'])
```

#### `values()`
Returns all values in the dictionary.

```python
print(fees.values())  # dict_values([5000, 4000])
```

#### `items()`
Returns all key-value pairs as tuples.

```python
print(fees.items())  # dict_items([('anand', 5000), ('ajay', 4000)])
```

#### `update()`
Updates the dictionary with key-value pairs from another dictionary.

```python
fees.update({"sapna": 6000})
print(fees)  # {'anand': 5000, 'ajay': 4000, 'sapna': 6000}
```

## Converting Lists to Dictionary

### Using `zip()` and `dict()`

`zip()` converts two lists into key-value pairs, and `dict()` converts them to a dictionary.

```python
roll = [100, 101]
name = ["Ajay", "Sapna"]
z = zip(roll, name)
d = dict(z)
print(d)  # {100: 'Ajay', 101: 'Sapna'}
```

---

# Comparison: List vs Tuple vs Set vs Dictionary

| Type | Syntax | Mutable | Speed |
|------|--------|---------|-------|
| List | `[]` | Yes | Fast |
| Tuple | `()` | No | Fastest |
| Set | `{}` | Yes | Slower than List |
| Dictionary | `{key: value}` | Yes | - |

# Functions

## Introduction

Functions are used to perform a task. You can write a function once and reuse it anywhere.

### Syntax

```python
def functionName(variable):
    # logic
    return result

functionName()  # Calling the function
```

## Return Statement

The `return` statement is used to return a value from a function.

### Example: Simple Function

```python
def sum():
    x = 10
    y = 20
    z = x + y
    return z

print(sum())  # Output: 30
```

## Function Parameters and Arguments

### Parameters
Variables defined in the function definition.

### Arguments
Actual values passed to the function when calling it.

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Ajay")  # "Ajay" is the argument
```

## Types of Functions

### 1. Function with No Parameters and No Return Value

```python
def hello():
    print("Hello World")

hello()
```

### 2. Function with Parameters and No Return Value

```python
def add(x, y):
    print(x + y)

add(5, 10)  # Output: 15
```

### 3. Function with No Parameters but with Return Value

```python
def get_value():
    return 42

result = get_value()
print(result)  # Output: 42
```

### 4. Function with Parameters and Return Value

```python
def multiply(x, y):
    return x * y

result = multiply(5, 4)
print(result)  # Output: 20
```

## Default Parameters

You can provide default values for parameters.

```python
def greet(name="Guest"):
    print(f"Hello, {name}!")

greet()  # Output: Hello, Guest!
greet("Sapna")  # Output: Hello, Sapna!
```

## Multiple Return Values

A function can return multiple values.

```python
def get_info():
    name = "Ajay"
    age = 20
    return name, age

name, age = get_info()
print(name)  # Ajay
print(age)   # 20
```
