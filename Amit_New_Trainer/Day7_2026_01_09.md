# String Iteration - Accessing Characters

## Iterating Through a String

### Method 1: Using for-in Loop
Iterate through each character using a for-in loop.

```python
name = "Python"

for k in name:
    print(k)
```

**Output:**
```
P
y
t
h
o
n
```

---

### Method 2: Using for Loop with range()
Iterate using index positions.

```python
name = "Python"

for i in range(len(name)):
    print(name[i])
```

**Output:**
```
P
y
t
h
o
n
```

---

## Practical Example: Password Validation

### Requirements:
- At least one digit
- At least one uppercase letter
- At least one special character

### Solution:

```python
password = "Abc123@"
upperBool = False
digitBool = False
specialBool = False

for i in password:
    if i.isdigit():
        digitBool = True
    elif i.isupper():
        upperBool = True
    elif i in ('@', '$', '!'):
        specialBool = True

if (digitBool == True and upperBool == True and specialBool == True):
    print("Valid")
else:
    print("Invalid")
```

**Output:** `Valid`

# Object-Oriented Programming (OOPs) in Python

## What is OOPs?

**Object-Oriented Programming (OOPs)** is a programming paradigm based on the concept of objects and classes.

### Key Benefits:
- 📦 **Modularity**: Code is organized into objects
- ♻️ **Reusability**: Write once, use anywhere
- ⚡ **Time Saving**: Faster development and maintenance
- 🔧 **Easy to Maintain**: Clear structure and organization
- 🧩 **Collection of Classes and Objects**: Organized and scalable

---

## Class vs Object

### What is a Class?

A **class** is a blueprint or template for creating objects. It defines the structure and behavior.

**Key Points:**
- Collection of objects
- Contains functions (methods) and properties (attributes)
- Reusable template

**Syntax:**
```python
class ClassName:
    def functionName(self):
        # code here
        pass
    
    def anotherFunction(self):
        # code here
        pass
```

**Example:**
```python
class User:
    # Logic for user
    pass
```

---

### What is an Object?

An **object** is a real-time entity created from a class. It is an instance of a class.

**Key Points:**
- Instance of a class
- Real-time entity
- Occupies memory
- Can use class functions and properties
- Each class must have at least one object

**Syntax:**
```python
objectName = ClassName()
```

**Example:**
```python
user = User()
```

---

## The `self` Keyword

`self` is a Python keyword that represents the current object instance. It allows you to access class functions and properties.

**Important:**
- `self` must be the first parameter in any method
- It refers to the specific instance of the class
- You use `self` to access attributes and call other methods within the class

---

## Accessing Class Functions

```python
class ClassName:
    def functionName(self):
        # code here
        pass

object = ClassName()
object.functionName()  # Calling the class function
```

---

## Practical Example: Addition Using OOPs

### Problem:
Write a program to perform addition using OOPs.

### Solution:

```python
class Maths:
    def add(self):
        x = 10
        y = 20
        result = x + y
        print(result)

# Create an object of the Maths class
m = Maths()

# Call the add method
m.add()  # Output: 30
```

**Output:** `30`

## Complete OOPs Workflow

```python
# Step 1: Define a Class
class Calculator:
    def multiply(self):
        a = 5
        b = 4
        print(f"{a} × {b} = {a * b}")

# Step 2: Create an Object
calc = Calculator()

# Step 3: Call the Method
calc.multiply()  # Output: 5 × 4 = 20
```

## Key Concepts Summary

| Concept | Definition |
|---------|-----------|
| **Class** | Blueprint for creating objects |
| **Object** | Instance of a class |
| **Method** | Function inside a class |
| **Attribute** | Variable inside a class |
| **self** | Reference to the current object |
| **Instance** | Individual object created from a class |

## Advantages of OOPs

✅ **Modularity**: Code is well-organized and structured  
✅ **Reusability**: Classes can be reused multiple times  
✅ **Scalability**: Easy to scale and maintain large projects  
✅ **Security**: Data encapsulation protects sensitive information  
✅ **Flexibility**: Easy to modify and extend functionality

## OOPs Pillars (Four Principles)

1. **Encapsulation**: Bundling data and methods together
2. **Inheritance**: Creating new classes from existing ones
3. **Polymorphism**: Same method name, different behaviors
4. **Abstraction**: Hiding complex implementation details
