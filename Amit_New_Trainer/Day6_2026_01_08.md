# Python Strings - Complete Guide

## What is a String?

A string is a sequence of characters enclosed in single quotes `'`, double quotes `"`, or triple quotes `'''` or `"""`. Strings are immutable in Python, meaning once created, they cannot be changed.

### Creating Strings

```python
# Single quotes
str1 = 'Hello'

# Double quotes
str2 = "World"

# Triple quotes (for multi-line strings)
str3 = '''This is a
multi-line
string'''

# Triple double quotes
str4 = """Another
multi-line
string"""
```

## String Functions in Python

### 1. **len()** - Get String Length
Returns the number of characters in a string.

```python
text = "Python"
print(len(text))  # Output: 6
```

---

### 2. **upper()** - Convert to Uppercase
Converts all characters to uppercase.

```python
text = "hello world"
print(text.upper())  # Output: HELLO WORLD
```

---

### 3. **lower()** - Convert to Lowercase
Converts all characters to lowercase.

```python
text = "HELLO WORLD"
print(text.lower())  # Output: hello world
```

---

### 4. **capitalize()** - Capitalize First Letter
Converts the first character to uppercase and the rest to lowercase.

```python
text = "hello world"
print(text.capitalize())  # Output: Hello world
```

---

### 5. **title()** - Title Case
Converts the first character of each word to uppercase.

```python
text = "hello world python"
print(text.title())  # Output: Hello World Python
```

---

### 6. **strip()** - Remove Leading/Trailing Whitespace

```python
text = "  hello world  "
print(text.strip())  # Output: hello world
print(text.lstrip())  # Remove leading spaces only
print(text.rstrip())  # Remove trailing spaces only
```

---

### 7. **split()** - Split String into List
Splits a string at a specified delimiter.

```python
text = "apple,banana,orange"
result = text.split(",")
print(result)  # Output: ['apple', 'banana', 'orange']

# Example from training:
email = "ankityahoo@gmail.co.in"
z = email.split("@")
print(z)  # Output: ['ankityahoo', 'gmail.co.in']
```

---

### 8. **join()** - Join List into String
Joins elements of a list into a single string.

```python
words = ['hello', 'world', 'python']
result = " ".join(words)
print(result)  # Output: hello world python
```

---

### 9. **replace()** - Replace Substring
Replaces all occurrences of a substring.

```python
text = "I love Java"
result = text.replace("Java", "Python")
print(result)  # Output: I love Python
```

---

### 10. **find()** - Find Substring Position
Returns the index of the first occurrence of a substring. Returns -1 if not found.

```python
text = "I love Python"
index = text.find("love")
print(index)  # Output: 2
```

---

### 11. **rfind()** - Reverse Find
Returns the index of the last occurrence of a substring.

```python
text = "I love Python"
index = text.rfind("o")
print(index)  # Output: 11 (last "o" in "Python")
```

---

### 12. **count()** - Count Occurrences
Counts how many times a substring appears in a string.

```python
text = "banana"
count = text.count("a")
print(count)  # Output: 3
```

---

### 13. **startswith()** - Check if String Starts With
Returns True if the string starts with the specified substring.

```python
text = "hello world"
print(text.startswith("hello"))  # Output: True
print(text.startswith("world"))  # Output: False
```

---

### 14. **endswith()** - Check if String Ends With
Returns True if the string ends with the specified substring.

```python
text = "hello world"
print(text.endswith("world"))  # Output: True
print(text.endswith("hello"))  # Output: False

# Example from training:
email = "ankityahoo@gmail.co.in"
valid_domains = (".com", ".in", ".org", ".net", ".co.in")
if email.split("@")[1].endswith(valid_domains):
    print("Valid")
```

---

### 15. **isalpha()** - Check if All Characters are Alphabetic
Returns True if all characters are letters.

```python
print("hello".isalpha())    # Output: True
print("hello123".isalpha())  # Output: False
```

---

### 16. **isdigit()** - Check if All Characters are Digits
Returns True if all characters are numbers.

```python
print("12345".isdigit())   # Output: True
print("123a5".isdigit())   # Output: False
```

---

### 17. **isalnum()** - Check if Alphanumeric
Returns True if all characters are alphanumeric (letters or digits).

```python
print("hello123".isalnum())  # Output: True
print("hello@123".isalnum()) # Output: False
```

---

### 18. **isspace()** - Check if All Characters are Whitespace
Returns True if all characters are whitespace.

```python
print("   ".isspace())  # Output: True
print(" a ".isspace())  # Output: False
```

---

### 19. **islower()** - Check if All Characters are Lowercase
Returns True if all characters are lowercase.

```python
print("hello".islower())   # Output: True
print("Hello".islower())   # Output: False
```

---

### 20. **isupper()** - Check if All Characters are Uppercase
Returns True if all characters are uppercase.

```python
print("HELLO".isupper())   # Output: True
print("Hello".isupper())   # Output: False
```

## Practical Example: Email Validation

```python
def validate_email(email):
    """
    Validates if an email has correct format
    """
    valid_domains = (".com", ".in", ".org", ".net", ".co.in")
    
    # Split email by @ symbol
    z = email.split("@")
    total = len(z)
    
    # Check if exactly one @ symbol exists
    if total == 2:
        # Check if domain ends with valid extension
        if z[1].endswith(valid_domains):
            print("Valid Email")
            return True
    else:
        print("Invalid Email")
        return False

# Test
email = "ankityahoo@gmail.co.in"
validate_email(email)  # Output: Valid Email
```

## String Indexing and Slicing

```python
text = "Python"
print(text[0])      # Output: P (first character)
print(text[5])      # Output: n (last character)
print(text[1:4])    # Output: yth (characters 1 to 3)
print(text[:3])     # Output: Pyt (first 3 characters)
print(text[3:])     # Output: hon (from 3rd to end)
print(text[-1])     # Output: n (last character)
print(text[-3:])    # Output: hon (last 3 characters)
```

## String Concatenation

```python
str1 = "Hello"
str2 = "World"

# Method 1: Using +
result = str1 + " " + str2
print(result)  # Output: Hello World

# Method 2: Using f-strings
result = f"{str1} {str2}"
print(result)  # Output: Hello World

# Method 3: Using format()
result = "{} {}".format(str1, str2)
print(result)  # Output: Hello World
```

---

## String Formatting

```python
name = "Python"
version = 3.9

# Method 1: % formatting
print("I love %s version %.1f" % (name, version))

# Method 2: .format()
print("I love {} version {}".format(name, version))

# Method 3: f-strings (Modern)
print(f"I love {name} version {version}")
```

---

## Key Points to Remember

- **Strings are immutable**: You cannot change individual characters
- **Indexing starts at 0**: First character is at index 0
- **Negative indexing**: -1 refers to the last character
- **Methods return new strings**: Original string remains unchanged
- **Case-sensitive**: "Hello" ≠ "hello"
- **Escape sequences**: `\n` (newline), `\t` (tab), `\\` (backslash), `\'` (quote)

---

## String Constants

```python
import string

print(string.ascii_lowercase)  # abcdefghijklmnopqrstuvwxyz
print(string.ascii_uppercase)  # ABCDEFGHIJKLMNOPQRSTUVWXYZ
print(string.digits)           # 0123456789
print(string.punctuation)      # !"#$%&'()*+,-./:;<=>?@[\]^_`{|}~
```
